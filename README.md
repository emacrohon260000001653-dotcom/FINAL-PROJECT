# Solara Resort Booking and Management System
Terminal-based Java 17+ academic project. Simulated payments only.

## Run
Open the project in Apache NetBeans, set Main Class to `solara.Main`, press F6.
Or from a terminal in this folder:

    javac -d out src/solara/*.java
    java -cp out solara.Main

## Demo Admin Login
- Username: admin
- Password/PIN: solara123

## Data
Saved automatically in the `data/` folder (reservations.txt, prices.txt).
Delete the folder to reset everything.
